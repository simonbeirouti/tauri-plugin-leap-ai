## Default Permission

Default permissions for the plugin

#### This default permission set includes the following:

- `allow-register-listener`
- `allow-remove-listener`
- `allow-download-model`
- `allow-load-model`
- `allow-load-cached-model`
- `allow-list-cached-models`
- `allow-remove-cached-model`
- `allow-unload-model`
- `allow-create-conversation`
- `allow-create-conversation-from-history`
- `allow-generate`
- `allow-stop-generation`
- `allow-export-conversation`
- `allow-runtime-info`
